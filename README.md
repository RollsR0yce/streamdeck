How to download the Stream Deck Controller app
1. Go to the download page
👉 https://github.com/RollsR0yce/streamdeck/releases

2. Download the latest version
At the top you'll see the newest release (e.g. v2.0.4). Click Assets (expand it if collapsed), then click the file:

StreamDeck.exe

The file will download automatically.

3. Run the app
Since the app isn't digitally signed, Windows may show a warning: "Windows protected your PC"

1.Click "More info"
2.Click "Run anyway"
This is normal Windows behavior for unsigned .exe files — the app is safe.

4. Done!
The app is now running. When a new version comes out, the app will automatically offer to update (an "Update Now" button will appear) — no need to manually download anything again.
